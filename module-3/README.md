#module 3 - combinational and sequential Logic Optimization
## Objective
The objective of Module 3 is to understand combinational and sequential logic optimization using Verilog RTL, simulation, and synthesis. The experiments help in understanding how RTL coding styles affect hardware implementation, area, timing, and logic utilization.
## Experiments

To understand the basic concepts of RTL optimization and how Verilog RTL can be written to obtain efficient hardware.

### Theory
RTL optimization is the process of modifying the RTL description of a digital circuit to improve hardware characteristics such as area, timing, and power while maintaining the required functionality.

### Procedure

1. Write the Verilog RTL design.
2. Compile the RTL code using the Verilog simulator.
3. Create a testbench to verify the design.
4. Run the simulation.
5. Observe the output waveform.
6. Analyze the synthesized hardware.
7. Compare the results before and after optimization.

### Result
The basic concepts of RTL optimization were studied and the effect of RTL coding on hardware implementation was understood.

# D3SK2 - Combinational Logic Optimization

## L1 - Lab06 Combinational Logic Optimization

### Objective
To understand the optimization of combinational logic using Verilog RTL.

### Theory
Combinational circuits produce outputs based only on the present input values. Examples include multiplexers, decoders, encoders, adders, and logic gates.

Optimization of combinational logic can reduce unnecessary gates and improve area and timing.

### Procedure

1. Write the combinational RTL design.
2. Create the testbench.
3. Compile the design.
4. Run the simulation.
5. Verify the output for different input combinations.
6. Synthesize the RTL.
7. Analyze the synthesized logic.
8. Identify possible optimization opportunities.
